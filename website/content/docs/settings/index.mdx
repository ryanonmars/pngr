---
title: "Settings"
description: "Preferences, monitoring defaults, graphs, and local storage."
---

Open **Settings…** from the application menu. The shortcut is **⌘,** on macOS and **Ctrl+,** on Windows.

Settings edits a draft. **Apply** saves it and leaves the window open; **OK** saves and closes it. **Cancel**, Escape, or closing the window discards changes since the last save. Settings apply immediately while monitoring continues. Invalid settings are reported in the window and are not applied.

The sidebar contains General, Monitoring, Display, History, Alerts & notifications, and Web Server. Buttons labeled **Apply & …** save the draft before opening the related tool.

- [General](/docs/settings/general): workspace restoration and data location.
- [Monitoring](/docs/settings/monitoring): defaults and selected-target configuration.
- [Display](/docs/settings/display): thresholds and graph visibility.
- [History and storage](/docs/settings/history-storage): retention and aggregation.
- [Alerts and notifications](/docs/settings/alerts-notifications): in-app and native notifications.
- [Web Server](/docs/settings/local-web-api): the optional localhost or authenticated LAN dashboard and API.
- [Probing profiles](/docs/settings/probing-profiles): reusable probe configurations.
