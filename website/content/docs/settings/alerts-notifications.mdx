---
title: "Alerts and notifications"
description: "Enable in-app alerts, native notifications, and recovery delivery."
---

Notification delivery is opt-in. No alert rules exist in a new workspace.

| Setting | Default | Behavior |
| --- | --- | --- |
| Show alerts inside Pngr | Off | Displays in-app notifications |
| Enable native desktop notifications | Off | Enables OS notification delivery |
| Notify when a connection recovers | On | Allows recovery notifications and external actions |
| Notification spacing | 30 seconds | 0–86400 seconds; shared across native notifications |

Click **Request OS notification permission…** to request permission. Pngr does not request it implicitly. OS permission and the native enable checkbox are separate requirements.

**Apply & edit alert rules / history…** opens the rule editor and event log. **Apply & configure email, webhooks and scripts…** opens the optional action editor.
