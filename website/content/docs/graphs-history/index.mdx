Pngr combines a route-aligned latency plot with a historical timeline. Select a target to inspect its hop table and destination measurements, then add hop graphs to compare the same interval.

- [Read the hop latency plot](/docs/graphs-history/hop-latency).
- [Understand the timeline](/docs/graphs-history/timeline).
- [Zoom, pan, and select an interval](/docs/graphs-history/navigation).
- [Compare synchronized graphs](/docs/graphs-history/synchronized-graphs).
- [Reopen saved sessions](/docs/graphs-history/saved-sessions).
- [Export measurements as CSV](/docs/graphs-history/csv-export).

<Callout type="warn">
Response loss means an eligible diagnostic probe did not receive a qualifying reply. It does not establish forwarding loss. A router may forward traffic normally while limiting or suppressing replies to Pngr.
</Callout>
