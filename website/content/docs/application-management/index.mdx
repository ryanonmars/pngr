---

Pngr provides manual update checks and launch-time update notifications. Downloads and installation require separate actions in the update window.

- [Check for updates and install a release](/docs/application-management/updates).
- [Uninstall or preserve application data](/docs/application-management/uninstalling).
- [Troubleshoot common problems](/docs/application-management/troubleshooting).

Pngr keeps installed application files separate from per-user monitoring data. The data directory retains the legacy TraceScope name for compatibility.
