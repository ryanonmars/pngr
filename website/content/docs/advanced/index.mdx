title: "Advanced features"
description: "Rules, alert delivery, network sources, maintenance, and the read-only API."
---

Pngr's advanced tools run inside the desktop application and store their configuration locally.

- [Alert rules and recovery](/docs/advanced/alert-rules): sustained conditions, scope, cooldown, and event acknowledgment.
- [Desktop notifications](/docs/advanced/desktop-notifications): native delivery on macOS and Windows.
- [Email, webhooks, and scripts](/docs/advanced/alert-actions): optional actions and secret references.
- [Network interface selection](/docs/advanced/network-interfaces): choose a source and inspect local network information.
- [Data maintenance](/docs/advanced/data-maintenance): workspace portability, retention, and compaction.
- [REST API reference](/docs/advanced/local-api): read-only measurements and history endpoints.
